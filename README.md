# OS2026

OS2026 实验小组仓库。每个小组使用一个公开仓库；每次实验使用一个独立分支，命名为 `lab1`、`lab2` 等。

每个实验分支应包含：

```text
code/                 # 本次实验实现后的源代码
report/
  report.md           # 实验报告（按课程模板撰写）
  prompt.md           # 本次实验使用的所有提示词汇总
  images/             # 报告中提及的测试结果截图
```

提交前检查报告引用的截图在 `report/images/` 中，且代码与报告都位于对应的 `labx` 分支。Git 不跟踪空目录，`images/` 尚无截图时可在实际提交时创建。
